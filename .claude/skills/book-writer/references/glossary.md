# 용어 통일 사전 (Standard Glossary — 산업안전보건 & 다중 에이전트)

본 사전은 집필(`chapter-writer`), 교정(`proofreader`), 통합(`consolidation`/`compile`) 과정에서 챕터 간 표기 불일치를 방지하기 위한 기준 문서입니다.

| 권장 표기 (Standard) | 지양 표기 (Deprecated) | 영문 원어 | 통일 이유 (Why) |
| :--- | :--- | :--- | :--- |
| **위험성평가** | 리스크 평가, 위험도 사정 | Risk Assessment | 산업안전보건법 제36조 및 고용노동부 고시의 법정 표준 용어로 통일 |
| **아차사고** | 니어미스, 유사사고, 아찔사고 | Near-Miss | 안전보건공단(KOSHA) 및 산업현장 표준 용어로 통일하여 독자 가독성 확보 |
| **물질안전보건자료(MSDS)** | 화학물질 시트, 안전데이터시트 | Material Safety Data Sheet | 산업안전보건법 제110조 법정 명칭 준수 |
| **작업허가제(PTW)** | 안전작업 승인서, 워크퍼밋 | Permit to Work | 화기·밀폐공간·고소작업 등 고위험 작업 통제 절차의 표준 명칭 |
| **개인보호구(PPE)** | 안전장구, 보호장비 | Personal Protective Equipment | 위험 통제 5단계 계층의 마지막 5단계 법정 용어 통일 |
| **오케스트레이션 하네스** | 조율 프레임워크, 지휘기 | Orchestration Harness | 에이전트들을 묶어 제어하고 런타임 안전장치를 제공한다는 아키텍처 의미 전달 |
| **단계적 정보 공개** | 점진적 노출, 지연 로딩 | Progressive Disclosure | 초기 컨텍스트 예산을 아끼고 필요 시점에 세부 워크플로를 로드하는 핵심 기법 |
| **우체국 안티패턴** | 중앙 집중 중계 오류, 메신저 병목 | Post-Office Anti-Pattern | 리더가 모든 안전 보고와 피드백을 대리 요약하며 핵심 위험 디테일이 손실되는 현상 |
| **최소 권한 원칙** | 권한 제한, 도구 축소 | Principle of Least Privilege | 검토 에이전트에게 `Write`, `Edit`을 배제하여 원고 및 안전 기록 무결성을 보호하는 원칙 |
| **컨텍스트 예산** | 토큰 한도, 메모리 크기 | Context Budget | 컨텍스트 윈도우를 유한한 공공재(Public Good)로 다루어야 함을 강조 |
| **매개변수 / 인자** | 파라미터 / 아규먼트 | Parameter / Argument | 함수 정의부의 변수는 '매개변수(Parameter)', 호출 시 전달하는 값은 '인자(Argument)'로 구분 |
| **메서드** | 메소드, 멤버 함수 | Method | 국립국어원 외래어 표기법 및 현대 기술 서적 표준 표기 준수 |
