# 용어 통일 사전 (Standard Glossary)

본 사전은 집필(`chapter-writer`), 교정(`proofreader`), 통합(`consolidation`/`compile`) 과정에서 챕터 간 표기 불일치를 방지하기 위한 기준 문서입니다.

| 권장 표기 (Standard) | 지양 표기 (Deprecated) | 영문 원어 | 통일 이유 (Why) |
| :--- | :--- | :--- | :--- |
| **오케스트레이션 하네스** | 조율 프레임워크, 지휘기 | Orchestration Harness | 에이전트들을 묶어 제어하고 안전장치를 제공한다는 아키텍처 의미를 명확히 전달하기 위함 |
| **단계적 정보 공개** | 점진적 노출, 지연 로딩 | Progressive Disclosure | 초기 컨텍스트 예산을 아끼고 필요 시점에 세부 워크플로를 로드하는 핵심 기법의 공식 명칭 통일 |
| **우체국 안티패턴** | 중앙 집중 중계 오류, 메신저 병목 | Post-Office Anti-Pattern | 리더 에이전트가 모든 메시지를 대신 전달하며 컨텍스트가 오염되는 현상을 직관적으로 지칭 |
| **최소 권한 원칙** | 권한 제한, 도구 축소 | Principle of Least Privilege | 검토 에이전트에게 `Write`, `Edit`을 배제하여 원고 무결성을 보호하는 보안 원칙 |
| **컨텍스트 예산** | 토큰 한도, 메모리 크기 | Context Budget | 컨텍스트 윈도우를 유한한 공공재(Public Good)로 다루어야 함을 강조 |
| **매개변수 / 인자** | 파라미터 / 아규먼트 | Parameter / Argument | 함수 정의부의 변수는 '매개변수(Parameter)', 호출 시 전달하는 값은 '인자(Argument)'로 엄격히 구분 |
| **메서드** | 메소드, 멤버 함수 | Method | 국립국어원 외래어 표기법 및 현대 기술 서적 표준 표기 준수 |
